# 数据类型语义约定

逻辑模型中的时间字段必须保留业务所需的日期信息，不能把预约日期和时刻只存成纯时间。

| 逻辑类型 | 含义 | 典型字段 |
|---|---|---|
| `DATE` | 仅业务日期 | 出生日期、资质有效日期、绩效周期起止 |
| `DATETIME` | 预约或排班的完整日期时间 | 预约开始/结束、排班开始/结束、改约前后时段 |
| `TIMESTAMP` | 事件发生时刻 | 创建、审核、签到、付款、审计 |
| `TIME` | 仅在确实只需要日内时刻时使用 | 本版核心表暂不使用 |
| `MONEY` | `DECIMAL(12,2)` | 价格、结算金额、收款金额 |
| `QUANTITY` | `DECIMAL(12,3)` | 治疗数量、耗材数量、库存数量 |

预约和排班采用半开区间 `[starts_at, ends_at)`，并要求开始时间早于结束时间。跨诊所查询和冲突检查必须以完整日期时间为依据。
