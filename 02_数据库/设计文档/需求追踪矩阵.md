# 需求到数据表追踪矩阵

| 用例 | 关键数据表 | 关键结果 |
|---|---|---|
| UC-01 预约就诊 | PATIENT、PATIENT_ALLERGY、DENTIST、PRACTICE、DENTIST_QUALIFICATION、SHIFT、APPOINTMENT、APPOINTMENT_REQUEST_ITEM | 建立患者、牙医、诊所、排班和预约关联 |
| UC-02 修改或取消预约 | APPOINTMENT、APPOINTMENT_EVENT、SHIFT | 保留原记录，记录新旧时段、状态和原因 |
| UC-03 维护患者档案与过敏史 | PATIENT、ALLERGEN、PATIENT_ALLERGY、AUDIT_EVENT | 维护统一患者主索引和过敏评估 |
| UC-04 确认到诊与未到诊 | APPOINTMENT、ENCOUNTER、AUDIT_EVENT | 形成到诊、取消或未到诊事实 |
| UC-05 查询历史就诊 | PATIENT、ENCOUNTER、TREATMENT_LINE | 按患者主索引查看跨诊所历史 |
| UC-06 记录检查与诊疗 | ENCOUNTER、TREATMENT_ITEM、PRICE_VERSION、TREATMENT_LINE、MATERIAL、TREATMENT_MATERIAL_USAGE | 形成可确认、可结算的治疗明细 |
| UC-07 维护标准治疗项目 | TREATMENT_ITEM、PRICE_VERSION、TREATMENT_REQUIRED_QUALIFICATION | 维护全局治疗项目和价格版本 |
| UC-08 生成结算单 | ENCOUNTER、TREATMENT_LINE、INVOICE、INVOICE_VERSION、INVOICE_LINE | 生成与一次就诊关联的逐行结算 |
| UC-09 患者收款 | INVOICE_VERSION、PAYMENT、ACCOUNT | 支持部分收款和唯一支付凭据，不含退款 |
| UC-10 查询结算记录 | INVOICE、INVOICE_VERSION、INVOICE_LINE、PAYMENT | 查询结算明细、收款状态和余额 |
| UC-11 维护牙医资质 | DENTIST、QUALIFICATION、DENTIST_QUALIFICATION、PRACTICE | 维护有效资质和跨诊所执业关系 |
| UC-12 提交调班与休假申请 | SHIFT_REQUEST、SHIFT_REQUEST_ITEM、REQUEST_APPOINTMENT_IMPACT、SHIFT | 记录申请、影响班次和受影响预约 |
| UC-13 审核并发布排班 | SHIFT、SHIFT_REQUEST、SHIFT_REQUEST_ITEM、DENTIST_QUALIFICATION | 校验资质和时间冲突后发布排班版本 |
| UC-14 查看运营与取消率 | APPOINTMENT、APPOINTMENT_EVENT、ENCOUNTER、TREATMENT_LINE | 派生到诊率、取消率和工作量 |
| UC-15 绩效与奖励 | DENTIST_PERFORMANCE、DENTIST、CLINIC、ACCOUNT | 保存周期运营绩效和奖励等级，不做奖金支付 |
