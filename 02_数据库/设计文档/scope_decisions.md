# 数据库设计范围决策

| 决策项 | 结论 | 原因 |
|---|---|---|
| 退款 | 删除 | Word 已删除退款业务；当前只保留患者收款和部分支付 |
| 保险理赔 | 不纳入 | 需求没有保险业务，OpenDental 的 claim 体系过于复杂 |
| 会计总账 | 不纳入 | 当前项目不是财务系统 |
| 工资与奖金发放 | 不纳入 | 避免把绩效扩展成薪酬系统 |
| 医疗用品成本 | 不纳入 | 库存只记录数量，不记录采购金额和成本 |
| 牙医绩效 | 保留简化结果表 | 覆盖 UC-15，但只保存周期运营指标和奖励等级 |
| OpenDental 表 | 选择性参考 | 430 张表中仅抽取与 ADC 需求直接相关的模式 |
| 运营指标 | 事实计算，周期快照 | 避免维护重复累计值造成不一致 |

## 绩效表规则

同一牙医、同一诊所、同一统计周期和同一指标口径版本只能有一条绩效结果。`reward_level` 是等级，不是金额；如未来需要真实奖金支付，应另行立项并重新设计财务范围。
